## 목표
실제 규모의 온톨로지(필드테스트 대상은 study_abroad 프로젝트의 PI 온톨로지, 약 2,000 트리플)로 CLI를 돌려 깨지는 곳을 찾고, WebProtégé 경계에서 생기는 손실이 드러나지 않고 지나가지 않게 한다.

## 완료 조건
- 강화 조사에서 나온 남은 항목이 처리된다.
  - `onto remove --prune-reification`([[I012]]).
  - `apply-edits` 업로드 전 IRI 사전 비교([[I010]]).
  - Playwright 고정 대기를 상태 기반 대기로 교체([[overview/strengthening]]의 S6).
- 라운드트립 손실 대응 후보가 결정되거나 구현된다([[I014]]).
  - provenance를 `owl:Axiom` 어노테이션으로 인코딩해 라운드트립에서 살아남는지 검증.
  - `onto validate --profile owlapi-safe`로 보존되지 않는 구문을 미리 차단.
  - `wp` push 뒤 자동 `onto diff`(post-push verify).
- CLI 명령 보강: `wp delete`(프로젝트를 휴지통으로 이동, 테스트 정리용), `wp export --unzip`([[I004]]), 선택적으로 export → 편집 → apply-edits를 묶는 `wp sync`, merge preview의 변경 건수·내용 정밀 파싱(지금은 근사치), 선택적으로 `onto add-cardinality`(min/max/exact, 지금은 functional로 최대 1만 표현).
- 테스트 보강: 여러 프로젝트가 있을 때의 목록 파싱 회귀 테스트, 로그인 실패·중복 가입 같은 에러 경로 테스트.
- 배포·문서: 선택적으로 읽기 전용 `/download` raw-HTTP 빠른 경로([[overview/control-surface]]).
