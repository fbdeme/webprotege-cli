---
title: "`validate --reason`이 OWL 2 datatype map 밖의 타입에서 중단됨"
status: closed
---
심각도: med. [[overview/strengthening]]의 S2에 해당한다.

## 문제
`onto validate --reason`이 HermiT(owlready2 경유)를 실행하는데, 실 PI 온톨로지의 `xsd:gYear`에서 `UnsupportedDatatypeException`으로 중단되어 결과가 나오지 않았다.

## 원인
HermiT는 OWL 2 datatype map에 있는 타입만 지원한다.

## 해결
- Pellet으로 대체하는 안은 기각했다. owlready2 0.51에 번들된 Pellet(Jena 의존)은 Java 25(class file 69)를 요구하는데 작업 머신은 Java 21(class file 65)이라, datatype과 무관하게 `UnsupportedClassVersionError`로 실행되지 않는다.
- 대신 datatype 완화 후 재시도를 넣었다. HermiT 중단 메시지에서 문제 datatype IRI를 뽑아, 추론용 임시 그래프에서만 그 타입의 literal과 `rdfs:range`를 불투명 string으로 바꾸고 다시 돌린다(지원하지 않는 타입마다 한 번). 사용자 파일은 바뀌지 않는다. 완화 내역은 `reasoner: relaxed …` 줄로 출력한다.
- 실 PI 온톨로지(약 2,000 트리플)에서 `xsd:gYear` 1건을 완화한 뒤 "consistent, no unsatisfiable classes"가 나온다. 회귀 테스트는 Java가 있을 때만 돈다. 파싱·구조 검사만 하는 `validate`는 원래 영향이 없었다.
