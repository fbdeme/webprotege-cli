## 문제
merge-upload(파일을 프로젝트에 반영하는 기능)가 어떤 경우에는 변경을 하나도 적용하지 않고 에러 없이 끝난다.

## 원인
`ModifiedProjectOntologiesCalculator.isDifferentVersionOfOntology`는 프로젝트 온톨로지와 업로드 온톨로지의 Ontology IRI가 같고 둘 다 익명이 아닐 때만 diff를 계산한다. IRI가 다르거나 익명이면 diff를 건너뛰어 변경 0건이 되고, 에러도 나지 않는다.

## 해결
- export로 프로젝트의 Ontology IRI를 확인하고, 편집본도 같은 IRI를 유지한다.
- `onto`는 저장할 때 Ontology IRI가 바뀌면 저장을 중단한다.
- 같은 IRI로 추가와 삭제가 모두 반영되고 새 리비전(R2)이 생기는 것을 라이브 인스턴스에서 확인했다.
- CLI 쪽 경고는 [[I010]]에서 추가했다. 흐름 전체는 [[overview/hybrid-editing]]에 있다.
